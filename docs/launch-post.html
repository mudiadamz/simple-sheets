Why build another spreadsheet app?

Most of the time you don't need a full office suite. You need to open a file someone sent you, check a few numbers, fix a typo, maybe sort a column, and send it back. For that, waiting for a heavyweight suite to load (or uploading the file to someone's cloud) feels like starting a truck to cross the street.

The lightweight alternatives have the opposite problem: they open fast, but the moment you save, the file comes back different. Colours gone. Charts missing. Column widths reset. Your colleague opens it and asks what happened.

Simple Sheets is built around one promise: open instantly, edit comfortably, and give the file back the way you found it, plus your changes.

Your files stay your files

When Simple Sheets saves a workbook it patches only what you changed instead of rebuilding the file from scratch. Fonts, fills, borders, number formats, conditional formatting, data validation, charts, pictures, shapes, sparklines, comments, pivot tables, sheet protection and even workbook passwords all come through a round trip intact.

And when a file contains something it genuinely can't keep, it tells you before saving, not after. No silent surprises.

Real Excel tables, really rendered

Table styles with banded rows, the ▼ filter buttons in the header, data bars inside cells and colour-coded statuses: everything you see here comes straight from the file's own formatting rules.

Filter by value, by a condition ("greater than 100", "top 10", "contains…") or simply by colour.

What's inside

Simple Sheets started as a viewer. Version 2.0 is a complete everyday spreadsheet editor:

Every common format

Opens .xlsx, .xlsm, .xlsb, .xls, .ods, .csv and templates. Saves .xlsx, .xlsb, .ods and .csv, including password-protected workbooks.

A real formula engine

Around 200 functions including XLOOKUP, FILTER, UNIQUE, LET and LAMBDA, with dynamic arrays that spill and smart recalculation.

Analysis built in

Pivot tables saved as real Excel pivots, charts, goal seek, scenarios, data tables and a solver with constraints.

Print & share

Print preview, PDF of one sheet, all sheets or just the selection, page breaks, HTML export and workbook comparison.

Import anything

A CSV wizard with encoding, delimiter and column-type preview, and one-click import of a table from any web page.

Safe by default

Unsaved work is kept every minute and offered back after a crash. It warns when Excel has the file open or a sync folder made a conflict copy.

Feels familiar on day one

If you've used Excel or Google Sheets, there's nothing to learn. The formula bar, the fill handle that continues 1, 2, 3 or Mon, Tue, Wed, Ctrl+A to grab the block of data around you, right-click to insert rows, sheet tabs at the bottom, and Ctrl+Z for absolutely everything.

A few things we added because we wanted them ourselves:

  • Command palette (Ctrl+Shift+P): type a few letters and run any command.
  • Flash fill (Ctrl+E): type one or two examples and let it finish the column.
  • Evaluate formula: watch a complicated formula work itself out, step by step.
  • Several workbooks in tabs in one window, plus a split view for long sheets.

Comfortable for everyone

Dark mode and a high-contrast theme. An adjustable interface size for big screens and tired eyes. A colour-blind-safe chart palette. Every action reachable from the keyboard, including picking, moving and resizing charts and pictures. The interface speaks English, Bahasa Indonesia and Español, and anyone can add a language with a small JSON file.

Light, private, yours

Simple Sheets is a single 20 MB program. It installs per user without administrator rights, or runs straight from a folder (or a USB stick) in portable mode. There are no accounts, no telemetry, and nothing is uploaded anywhere. Updates are optional; when you turn them on, every download is checked against its SHA-256 checksum before it ever runs.

For IT departments, the installer runs silently with /S:

SimpleSheets-Setup.exe /S /D=C:\Tools\SimpleSheets /noopenwith

Built to be trusted

Under the hood Simple Sheets is plain Python with just two small libraries for reading spreadsheet files. Every change runs through more than 800 automated tests, including files that are opened, saved and compared part by part with the original, so "it didn't break my file" isn't a hope, it's checked.

It's also open about what isn't finished yet. The installer isn't code-signed yet, so Windows may show a SmartScreen notice the first time. Excel slicers aren't kept on save yet (you'll get a warning). The Linux and macOS builds are still experimental. And full screen-reader support is on the roadmap, with the groundwork already planned.

Try it

Grab the installer or the portable zip, open the spreadsheet you've been meaning to look at, and see how fast "just checking something" can be. The project lives on GitHub, where you can read the code, follow the roadmap and report anything that doesn't feel right.
